HOW TO USE

Calculate without thinking about the interface.

Use +, −, × and ÷ for arithmetic. Parentheses follow normal operator precedence, so 2 + 3 × 4 evaluates to 14. Use % as a percentage value, and ± to change the current number's sign.

Long results are formatted for readability. Very large or very small finite results switch to scientific notation. Invalid expressions and division by zero show a clear error instead of crashing.

For a dedicated percentage workflow, use the Numvero percentage calculator.
